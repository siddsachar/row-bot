# Release checklist

1. Freeze the level list 5 working days before release.
2. Run the full playtest (2 testers, at least 90 minutes each).
3. Bump the version in `pyproject.toml` and tag `v<version>`.
4. Upload the bundle to the publisher portal at least 3 days before launch.
5. The publisher needs the store screenshots at 1920 x 1080.
