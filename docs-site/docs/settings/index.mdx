# Settings

Settings is where Row-Bot is configured: where models come from and which one does each job, memory and documents, tools and extensions, accounts and channels, and how Row-Bot runs on this computer and your other devices.

Open it with **Settings** at the bottom of the sidebar. The pages are grouped down the left side; **Find a setting** (press / on a Settings page) searches page names and individual settings and jumps to the exact row. The command palette finds them too, and can flip common switches in place. On a phone, a **Settings section** list at the top replaces the side list; every page and setting is still there.

## How Settings Is Organized

| Group | Page | What it changes |
| --- | --- | --- |
| **General** | [Preferences](/docs/settings/preferences) | The assistant's name and personality, learning new skills, how Row-Bot opens, and the overnight Dream Cycle. |
| | [Appearance](/docs/settings/preferences#appearance) | Theme, accent colour, density and transparency on this device, and panel sizes. |
| | [Buddy](/docs/settings/buddy) | Your companion's look, personality and motion, and the desktop overlay. |
| **Models** | [Providers](/docs/settings/providers) | Where models come from: local, subscription, pay-per-use and custom endpoints. |
| | [Models](/docs/settings/models) | Which model does each job (Brain, Vision, Image, Video), limits for long work, and the catalog. |
| | [Voice](/docs/settings/voice) | Talk, dictation and read-aloud. |
| **Knowledge** | [Memory](/docs/settings/knowledge) | Remembering on or off, graph health and the wiki vault. Memories themselves live in Home › Knowledge. |
| | [Documents](/docs/settings/documents) | Files Row-Bot can search, and where search runs. |
| | [Tracker](/docs/settings/tracker) | Habits, symptoms and health events you track. |
| **Capabilities** | [Tools](/docs/settings/tools) | Capability loading, retrieval compression, search tools, built-in tools and custom tools. |
| | [Skills](/docs/settings/skills) | Find, add, try and remove skills, and create or edit your own. |
| **Connections** | [Apps](/docs/settings/apps) | The services Row-Bot can work in: find, connect, choose what each may do, turn off and remove. |
| | [Accounts](/docs/settings/accounts) | GitHub, Google (Gmail and Calendar) and X. |
| | [Channels](/docs/settings/channels) | Telegram, WhatsApp, Discord, Slack and SMS. |
| **System** | [System](/docs/settings/system) | The workspace folder, what Row-Bot may do (commands, files, browser and computer use), and logs. |
| | [Devices & remote access](/docs/operations/remote-access) | Connect a phone or computer, your signed-in devices, network access and the public link. |
| | [Updates](/docs/operations/#update-repair-and-uninstall) | The version you have, the update channel, and checking for updates. |
| | [Data](/docs/operations/#back-up) | Back up and restore, import from another assistant, and irreversible clean-up. |

Goals belong to one conversation and are set in its details card; agent profiles are managed in the sidebar's **Agents** dialog. See [Profiles, Goals, And Agents](/docs/profiles-goals-agents/).

All authenticated owner sessions see the same settings on every device. On phones and tablets, the layout adapts to the screen; the available settings and authority do not change.

## A Good Setup Order

1. Providers
2. Models
3. Documents and Tools
4. Apps and Skills
5. System access
6. Accounts and Channels
7. Voice and Buddy
8. Preferences and Appearance

## Safety Notes

Credentials belong in Providers, Accounts, Channels, or an app's setup in Apps, not in chat messages. Turn on only the tools and apps you intend to use. Review approvals before actions that write files, run commands, use accounts, contact external services, or send messages.
