# Settings: Plugins

Packages now live in **Settings → Integrations**. Inspect a native Row-Bot package or portable Agent Plugins 1.0.0 package before adding it. Native configuration, protected secret fields, preparation and health checks remain in the package details. Portable skills and MCP connections appear as children of one parent.

Enabling a package does not bypass tool approvals or profiles. Test and accept a portable MCP child’s tools separately. Foreign host entry points and hooks are not executed. Updates preserve package identity and settings, keep one previous managed file revision, and expose explicit recovery. Remove preserves data and credentials; **Delete saved data** removes only that package’s retained state.

See [Integrations](/docs/settings/integrations) for the complete workflow and compatibility limits.
