# Settings: Plugins

Settings no longer has a Plugins page. Packages are added, turned off and removed in **Settings › Apps**, and the apps and skills a package brings show **Installed as part of _package_**. Read [Settings: Apps](/docs/settings/apps) and [Plugins](/docs/integrations/plugins).

Old Plugins links open the matching place in Row-Bot.
