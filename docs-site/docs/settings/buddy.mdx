# Settings: Buddy

Buddy is Row-Bot's companion: a painted character that comes alive on your screen. It breathes, blinks, looks at your cursor, leans in while Row-Bot thinks, hops when work finishes and looks worried when something fails. Everything about how it moves runs on your computer; nothing is downloaded or generated while it animates.

It starts in the sidebar and, in the native Windows and macOS apps, can be dragged out onto the desktop as a pet. The pet's speech bubble is a smaller view of the thread selected in Row-Bot: it uses that thread's model, tools, approval mode, saved draft, and conversation rather than starting a separate assistant.

## Where To Find It

Open **Settings**, then choose **Buddy** in the **General** group, or search for it with **Find a setting**.

## Put Buddy On The Desktop

1. Turn on **Show Buddy** if the companion is hidden.
2. Press and drag Buddy itself away from its sidebar dock, or choose **Pop out Buddy**. Releasing it back over the dock cancels the move.
3. Let go where you want it. Buddy lands on whatever is under its feet: the top edge of a window, or the floor above the taskbar (Windows) or the Dock (macOS).
4. Drag Buddy whenever you want to move it. It stays always-on-top, but only Buddy itself and its open bubble take clicks; the empty space around it passes clicks to whatever is underneath.

When Buddy sits on a window, it rides along as that window moves. If you switch to another window and keep using it for a few seconds, Buddy hops over to it (at most every 20 seconds, never while its bubble is open or while you drag it). If its window closes, is minimised, maximised or goes full screen, Buddy floats down to the floor. Drop it on the taskbar or desktop to stop it following until you drop it on a window again, or turn off **Sit on the window I'm using** below.

The desktop pet requires the native Windows or macOS application. Browser/server mode, Linux browser-first launch, and the phone layout keep Buddy inside Row-Bot.

## Message The Selected Thread

Click Buddy to open its bubble. Buddy also opens it by itself for an approval, a question, a response that failed or was interrupted, and a finished reply (which tucks away again after a few seconds unless you are typing in it). Press Esc or click Buddy to close it.

The title at the top of the bubble identifies the thread that will receive your next message. Buddy follows the conversation selected in the main Row-Bot window: switch conversations there and Buddy switches with you. The smaller line shows whether that thread is a Chat, Code, or Design conversation and what it is doing. If no thread is selected, Buddy follows your most recent conversation.

- Type into **Message this thread...**. Enter sends; Shift+Enter adds a line.
- The full composer and the bubble share the saved draft for each thread. Switching threads loads that thread's draft without merging it into another conversation.
- Sending captures the thread and the Chat, Code, or Design context shown at that moment, so changing the main-window selection during a run does not silently retarget the request.
- After sending, the bubble shows current progress, the latest response, or an error. If a response was interrupted (for example by a restart), **Resume** continues it.
- Use **Stop** to stop the selected thread's active response. Buddy does not retry the turn by itself.
- Attachments, transcript history, tool traces, model selection, and microphone controls remain in the full Row-Bot thread. Use **Open full thread** when you need them.

The bubble is a text composer, not a second microphone session. When Row-Bot reads a reply aloud in the main window, Buddy's mouth moves with the voice there. Talk and Dictate remain in the full thread. A voice turn submitted there belongs to the same conversation and its progress can still appear in Buddy.

## Review Approvals

Buddy never creates a separate approval policy. It projects the selected thread's existing gate:

- The current approval shows **Deny**, **Details**, and **Approve** in the bubble. Ctrl+Enter (Cmd+Enter on macOS) approves.
- **Details** opens the full thread so you can inspect the complete request before deciding.
- If the selected thread or pending generation no longer matches, Buddy opens the full thread instead of approving a stale request.

## Buddy's Menu And Lifecycle

Right-click Buddy (or use the buttons in its bubble):

- **Open Row-Bot** (**Open full thread** in the bubble) restores the main Row-Bot window at the selected conversation.
- **Dock Buddy** returns Buddy to its sidebar dock.
- **Hide Buddy** hides it without docking. Use the tray's **Show Buddy** action to bring it back.
- While Buddy is torn off, closing the main Row-Bot window hides that window instead of quitting the app. Use **Open full thread**, **Open Row-Bot** in the tray, or the tray's quit action as appropriate.
- Tear-off is session-scoped. A fresh Row-Bot launch resets placement to the sidebar dock; a saved hidden preference remains hidden until you show Buddy.
- The bubble follows Row-Bot's appearance setting (System, Light, or Dark). With your device's reduced-motion setting on, Buddy stays still apart from blinking and its expressions.

## Appearance Controls

The Buddy page follows the conversation you have open, because Buddy uses that conversation's profile and approvals; open a conversation first if it asks.

- **Show Buddy** shows or hides the companion.
- **Look** chooses one of the six bundled Buddies or one you made. **New look…** makes one with your image model; **Refresh looks** reads them again.
- **Personality** changes the tone of Buddy's status cues.
- **Bubbles** changes how visual status appears.
- **Sit on the window I'm using** (native apps) lets the desktop Buddy follow you from window to window.
- **Motion** chooses how lively Buddy is: **Calm**, **Normal** or **Lively**.
- **Advanced Buddy settings** holds Buddy's **Name**, optional **Style notes** for new looks, and **Compact size**.

Buddy's picture is also the speaker mark beside Row-Bot's replies in conversations.

## Make A New Look

**New look…** opens the hatch. Describe the Buddy you want, optionally pick a body (**Floater**, **Little biped**, **Winged**, or **Pick for me**, which chooses from your description), and choose **Hatch Buddy**. Your image model paints the character, then paints six small edits of it (eyes closed, mouth open, happy, worried, focused and surprised); Row-Bot cuts it out, fits it with bones and turns the edits into its expressions, all on your computer. That is seven image requests to your provider, which may cost credits. Your current look stays until the new one is ready, and **Stop Hatch** stops it.

Image models that only make new pictures (such as Imagen) cannot paint the expressions; choose a GPT Image or Nano Banana model in Settings › Models.

A look made before Row-Bot 5.3.4 comes alive from its picture without any request. To give it blinks and expressions too, select it and choose **Bring to life** (six image requests).

## Common Workflow

1. Select the thread you want and confirm its name in the main window.
2. Drag Buddy out of the sidebar, click it, and confirm the same name appears at the top of its bubble.
3. Type a short message, review any approval, and use **Open full thread** when you need the complete transcript or tool details.
4. Use **Dock Buddy** when you want it back in the sidebar.
5. Make a new look only after an image model is ready in Settings › Models; choose **Calm** motion if animation is distracting.

## What Is Saved

Buddy visibility, appearance, where it last sat on the desktop, and thread drafts are local app data. The bubble does not copy conversations into a second store. Making a new look calls your configured image model; animating Buddy never does.

## Privacy And Safety

The bubble follows the same privacy and safety boundaries as the selected thread. A hosted model, tool, account, channel, MCP server, plugin, or media provider can still send data externally when that thread uses it. Undocking Buddy does not grant new permissions or bypass approvals.

To sit on your windows, the desktop Buddy reads the position and size of the window you are using, and where your cursor is so it can look at it. It never reads window titles, app names, contents or pixels, and none of this leaves your computer. Turn off **Sit on the window I'm using** to stop it following windows.

## Troubleshooting

- If Buddy does not appear in the sidebar, turn on **Show Buddy** and reload the current page if needed.
- If a drag snaps back, start the gesture on Buddy itself and release away from the original dock. Drag-to-undock is unavailable outside the native Windows and macOS apps.
- If a hidden desktop Buddy is still torn off, use **Show Buddy** from the system tray.
- If Buddy keeps hopping to windows you don't want it on, drop it on the taskbar or Dock, or turn off **Sit on the window I'm using**.
- If Row-Bot's main window is hidden, use **Open Row-Bot** from the tray or **Open full thread** from Buddy.
- If the bubble shows the wrong conversation, select the intended thread in Row-Bot and verify the bubble's title before sending.
- If an approval needs more context, choose **Review** or **Details** and decide in the full thread.
- Restart Row-Bot to reset desktop placement to the sidebar dock. Then enable **Show Buddy** if a saved hidden preference keeps it out of view.
- If making a new look fails, check that an image model that can edit pictures is chosen and its provider is connected.
- If Buddy shows as a still picture, your computer could not start its animation (no WebGL 2); everything else works.
