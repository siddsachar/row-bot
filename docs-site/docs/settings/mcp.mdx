# Settings: MCP

Settings no longer has an MCP page. MCP connections are apps in **Settings › Apps**; catalogs, runtimes, **Apps in chats** and **Add a custom connection** are under **Apps › Advanced**. Read [Settings: Apps](/docs/settings/apps) and [MCP](/docs/integrations/mcp).

Old MCP links open the matching place in Row-Bot.
