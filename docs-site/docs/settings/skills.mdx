# Settings: Skills

Skills now live in **Settings → Integrations**. Choose **Skills**, then **Installed** or **Discover**. One explicit **Search** uses eligible catalogs such as ClawHub; typing and Installed filtering stay local. Optional skills.sh discovery is unavailable until its documented desktop access requirements are resolved. Open a skill to review its complete file list and scanner findings before adding it off. Availability and pinning stay in its details. Local creation, import and proposals remain under **Advanced configuration and existing editors**.

Public updates require a fresh file review. One prior managed revision can be restored; edited local skills are never silently overwritten. Skill instructions do not grant tool access, credentials or approvals. Automatic selection and per-task activation remain unchanged.

See [Integrations](/docs/settings/integrations) and [Progressive Tools And Skills](/docs/guides/progressive-tools-and-skills).
