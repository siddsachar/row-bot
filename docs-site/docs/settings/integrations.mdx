# Settings: Integrations

Settings no longer has an Integrations page. What it held now lives on two pages:

- Services Row-Bot can work in, packages, catalogs and custom connections: **Settings › Apps**. Read [Settings: Apps](/docs/settings/apps).
- Skills: **Settings › Skills**. Read [Settings: Skills](/docs/settings/skills).

Old Integrations links open the matching page in Row-Bot.
