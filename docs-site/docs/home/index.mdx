# Home

Home is the start page for everything that isn't a single conversation. Choose **Home** in the sidebar, then one of its five tabs:

- [Overview](/docs/home/overview) asks Row-Bot anything, lists what needs you, and shows live status and recent work.
- [Workflows](/docs/home/workflows) lists saved workflows and reminders, runs them in one click, and opens the workflow editor.
- [Knowledge](/docs/home/knowledge) shows the memory graph and the full memory library, with review, editing and Dream Cycle.
- [Monitor](/docs/home/monitor) keeps the latest health checks with one-click fixes, plus activity, history and logs.
- [Insights](/docs/home/insights) lists what Row-Bot noticed and the proposals it prepared for your review.

Designs and code folders are not Home tabs: each opens in its conversation's panel. See [Designs](/docs/designer/) and [Code Folders](/docs/developer/).
