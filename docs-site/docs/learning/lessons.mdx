# Learning: Lessons

A lesson is a short "do it this way" that Row-Bot recalls when it's relevant, such as "When two documents share a title, choose by ID and say which one you picked." Lessons lists the lessons Learning put into use, and the lessons Row-Bot saved for itself during chats.

## Where To Find It

Choose **Home › Learning**, then **Lessons**. **Search lessons** finds a lesson by its title or words.

## What A Row Shows

Each row shows the lesson's title, its status, and a line under it:

- for a lesson Learning put into use, its kind of work and how often it was used: "Document lookups · used 12 times this month", or "not used yet this month";
- for a lesson Row-Bot saved for itself: "Saved by Row-Bot during a chat", with when.

Open a row to read the lesson's words.

| Status | What it means |
| --- | --- |
| **In use** | Row-Bot recalls it when it's relevant. A reply that used it says "Used a lesson". |
| **Off** | It was in use and you turned it off or undid it. |
| **Memory removed** | Its memory was deleted somewhere else, such as Home › Knowledge, so Row-Bot doesn't use it. If you undo that removal, it shows **In use** again. |
| **Not tested** | Row-Bot saved it for itself during a chat, and nothing has tested it. |
| **Testing** | It's being tested. |
| **Tested: helps** | Its test found it helps. |
| **Tested: no help** | Its test found no clear gain. |

## What You Can Do

From a row's **⋯** menu:

- **Turn off** takes a lesson in use out of use at once, like **Undo** in Changes.
- **Test it** tests a lesson Row-Bot saved for itself, the way every change is tested. A row marked **Not tested** also has a **Test it** button.
- **Delete** removes the lesson. A lesson in use is taken out of use first. A lesson Row-Bot saved for itself is a memory, and Delete deletes that memory too.

## Lessons And Memory

A lesson in use is saved as a memory of how to work, so it also appears in Home › Knowledge, and recall finds it like any memory. If you delete that memory in Knowledge, the lesson here shows **Memory removed** and Row-Bot stops using it; **Delete** here removes it from Lessons too. See [How Memory Becomes Knowledge](/docs/concepts/memory-knowledge-and-dream-cycle#lessons-from-learning).

Lessons in use stay in use while Learning is paused or off, and after you delete learning data.

## Empty States

- "No lessons yet. Lessons Row-Bot learns from your work show here once they pass their tests and you use them."
- "No lessons match …" when a search finds nothing.

## Troubleshooting

- **A lesson isn't used**: recall brings it up only when a request is about what it covers. Check its status and its count for this month.
- **A lesson is wrong**: **Turn off** or **Delete** it. Use **Teach** on the reply that went wrong so Learning can find a better one.
