# Plugins

A package (plugin) bundles several things, such as apps, skills and settings, under one name. Packages are managed in [Settings › Apps](/docs/settings/apps) like any other app.

## Add A Package

Find it in **Settings › Apps**, or use **Add from link or file** with a GitHub repository or a .zip file. Package rows from the Hermes catalog say **Checked when you add**: Row-Bot checks what the package contains when you add it, not while you browse. Nothing is downloaded or run until you agree on its page.

The package page's **Included** section lists what it brings. Each of those items says **Installed as part of _package_** and is managed through the package. Finish any app inside it that still needs a sign-in or a key from its own page.

## Turn Off And Remove

- **Turn off** stops the package and everything it brought. Settings and keys are kept.
- **Remove…** removes the package and everything it brought. Its saved keys and data are kept unless you choose **Also delete saved keys and data**.

Shared runtimes such as Node.js and uv stay installed.

## Safety

A package does not skip approvals or agent profile limits; its apps follow the access you choose for them. Code a package runs on this computer is not sandboxed, so add packages only from publishers you trust. Hooks and entry points written for other assistants are not run.

See [Extend Row-Bot](/docs/extending/) for how packages compare with skills, apps and Custom Tools.
