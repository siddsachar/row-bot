# MCP

MCP lets Row-Bot use tools exposed by external Model Context Protocol servers. An MCP server can be local or remote, simple or powerful. Treat it like an extension with its own access and trust boundary.

## Setup Workflow

1. Open Settings › MCP. The command palette finds it as "add mcp server".
2. Choose **Add a server**, then **Browse**, **Manual** or **Paste JSON**.
3. Review the command, arguments, URL, transport, and expected tools. A new server is saved turned off.
4. Install a runtime under **Runtimes (Node.js, uv)** if the server needs one.
5. Choose **Test connection**, then **Connect**.
6. Open **Details** to review its tools and permissions, and disconnect it if they reach more than you want.

## Controls

- **Use MCP servers** turns MCP on or off; **Offer MCP tools in chats** decides whether conversations can use MCP tools.
- **Runtimes (Node.js, uv)** installs the runtimes many servers need.
- **Add a server** browses a directory, takes the details by hand, or imports pasted JSON.
- Each server's button connects, turns on and connects, or disconnects it, and its status says **Connected**, **Couldn't connect** or **On · not connected**.
- Each server's **⋯** menu opens **Details** (connection, tools, permissions), **Test connection**, **Edit settings…**, **Rename…** and **Remove server…**.

## Safety

MCP tools can read, write, call APIs, or automate services depending on the server. Row-Bot approvals still matter, but you should also trust the server itself before enabling it.

## Troubleshooting

- If a server fails to test, check transport, command, arguments, URL, and dependencies.
- If tools are missing, check **Use MCP servers**, **Offer MCP tools in chats** and the server's own status.
- If a prompt asks for unexpected access, reject it and inspect the server configuration.
