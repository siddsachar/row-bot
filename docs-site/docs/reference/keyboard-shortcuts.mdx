# Keyboard Shortcuts

On macOS use ⌘ where Windows and Linux use Ctrl.

## Everywhere

| Shortcut | Action |
| --- | --- |
| ⌘K / Ctrl+K | Open the command palette |
| ⌘⇧O / Ctrl+Shift+O | New chat |
| Ctrl+` | Open or close the terminal |
| Esc | Close the palette, a menu or a dialog |
| / | Find a setting, on a Settings page |

## In A Conversation

| Shortcut | Action |
| --- | --- |
| Enter | Send |
| Shift+Enter | New line |
| ⌘F / Ctrl+F | Find in the conversation |
| ⌘. / Ctrl+. | Show or hide the conversation details card |
| ⌘Enter / Ctrl+Enter | Approve the focused approval |
| 1–4, then Enter | Pick an option on a question card, then answer |
| `@` | Mention an app, an agent, a resource or a file |
| `/` | Choose a skill or a [slash command](/docs/reference/slash-commands) |

## Models, Designs, Terminal And Computer Use

| Shortcut | Action |
| --- | --- |
| Shift+F10 on a model row | Star it, or take its star away |
| ⌘Z and ⌘⇧Z / Ctrl+Z and Ctrl+Shift+Z | Undo and redo in the Design panel |
| Ctrl+C in the terminal | Stop the command that is running |
| Esc while computer use runs | Stop computer use at once |
