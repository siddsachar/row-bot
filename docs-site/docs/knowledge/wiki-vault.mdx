# Wiki Vault

Wiki Vault writes your memories and their connections as linked Markdown articles in a folder you choose, so you can read them in Obsidian or any editor. It is an output of the local knowledge graph, not a replacement for the underlying memory and provenance records.

## Configure The Vault

1. Open **Settings › Memory** and find **Wiki vault**.
2. Turn on **Enable Wiki Vault** and choose the vault folder with **Browse**. Choosing a folder needs the Row-Bot desktop app; pick a folder separate from application code and important personal notes while you test.
3. Save the configuration, then use **Rebuild managed wiki files** to write every article.
4. Open the articles in your editor and check links, titles and source notes.

Articles have readable names: a memory called "Garden plan" becomes `Garden plan.md` in the folder for its type. When two memories share a name, or a note of your own already uses it, Row-Bot adds a short code to the new file name instead of overwriting anything. A renamed memory's article is renamed with it.

## What Row-Bot Writes And Leaves Alone

Row-Bot keeps a record of the articles it wrote and only ever updates or moves those. Notes you create yourself in the vault are never changed or deleted. Articles from an earlier version are adopted in place with the same names, so existing links keep working. Files Row-Bot replaced are moved aside for your review, not deleted; **Show moved files** lists them.

## Your Edits

When you edit an article in the vault, **Sync vault edits** brings the change back to the memory. If the memory changed in Row-Bot too, **Resolve versions** lets you choose between the database version and the vault version. Correct important facts in Knowledge first when you can, so the graph remains the source of truth.

## Privacy

The vault is local, but it is deliberately easy to open in other software or sync with a third-party folder. Treat the destination as an export boundary. Review it before placing it in cloud storage, a shared repository, or a publishing system.

## Troubleshooting

- If articles are missing, check that memory is on and the vault folder reads **Available**, then rebuild.
- If **Browse** opens no folder picker, use the Row-Bot desktop app; a browser can't choose folders on this computer.
- If links duplicate, run Knowledge repair before rebuilding the vault.
- If private material appears, correct or remove its source memory, rebuild, and review the destination before sharing.
