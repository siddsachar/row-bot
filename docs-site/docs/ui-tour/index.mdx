# UI Tour

Use this short tour if you want the quickest mental map before reading detailed pages.

1. Start with the [Row-Bot Interface](/docs/app-shell/navigation): the sidebar, Home, a conversation and its details card, panels, the terminal, and the ⌘K command palette.
2. Read [Home: Overview](/docs/home/overview), the first page Row-Bot opens: the Ask box, what needs you, live status and recent work.
3. Read [Chat](/docs/chat/) for conversations, the composer, models, attachments, tool traces and approvals.
4. See how a conversation works on a design or code folder in [Designs](/docs/designer/) and [Code Folders](/docs/developer/).
5. Open [Settings](/docs/settings/) when you are ready to connect providers, choose models, and set up memory, tools, accounts, channels and devices.
6. Keep [Privacy And Safety](/docs/privacy-safety/) nearby when enabling external services or action tools.
