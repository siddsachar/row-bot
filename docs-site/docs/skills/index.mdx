# Skills

Skills are instruction packs that teach Row-Bot how to approach a category of work. **Settings › Skills** is where you find skills, add them, try them, and create or edit your own (the command palette's **Add a skill** goes there). Skills you have added can also be discovered and loaded progressively when a task clearly matches their purpose.

See [Settings: Skills](/docs/settings/skills) for the page itself.

## UI Walkthrough

- **Search** finds skills in the library on this computer; **Search online catalogs** asks catalogs such as ClawHub.
- **Your skills** lists the skills you have added, built-in and your own.
- **A skill's page** shows its slash command (**Use it in chat with /_name_**), whether chats use it and which agent profiles include it, and **What's inside**: its files and scripts.
- **Add** adds the skill and turns it on. Scripts inside it never run when it is added.
- **Try it** opens a new chat with a draft that uses the skill; nothing is sent until you send it.
- **⋯ › Turn off** stops chats using it, and **⋯ › Remove…** deletes a skill you added or created.
- **⋯ › Advanced settings** opens the skill editor, where you edit and pin the skill and review proposed changes.

## Creating A Skill

1. Choose **Create a skill** in Settings › Skills.
2. Decide what task the skill should help with.
3. Write concise instructions, examples, and boundaries, including when the skill should and should not be used.
4. Save it.
5. Test it with **Try it** or a small prompt.
6. Revise if Row-Bot overuses or misunderstands it.

## Save How Row-Bot Did Something

Any reply whose work used tools has **Save as skill** (a bookmark icon) in its actions. Row-Bot drafts a skill from what it actually did in that turn, on the chat's own model, and opens it for you to review.

Row-Bot also offers this by itself, but only when a skill looks really worth it. A line under the reply names the task: **Save “Monthly expense report” as a skill?** It offers only when all of these hold:

- the work was in your own chat (never an incognito chat, one that was incognito, a channel chat, a helper's, a workflow's or Proactive Row-Bot's);
- it took at least five real steps with three different tools, and it made or changed something: research, lookups and questions never get an offer;
- every step ran (none was denied or blocked) and no skill you have already covers it;
- there is a reason to expect it again: you did something like it in another chat in the last 30 days, you showed Row-Bot how you wanted the steps done, it took a few tries to get right, or you said it comes round again ("every month", "weekly", "like last time");
- one short check on the chat's model agrees a skill would make it faster or more reliable next time, and names what changes each time.

Row-Bot offers at most three a day and one per chat. **Not now** hides that task for 30 days, and three in a row pause offers for two weeks.

The review sheet shows **Why Row-Bot offered this**, **What it will do** and the SKILL.md itself, with the chat it came from:

- **Approve** saves the skill and turns it on, so it loads by itself when a request matches. It isn't pinned. The notice that follows has **Undo**.
- **Edit** changes its name, what it does, when to use it, what changes each time, its steps and its checks. Your edit is final: no model rewrites it.
- **Reject** asks why, and Row-Bot won't offer that task again for a while.

Nothing is saved until you approve, and a draft never adds links, addresses, credentials or permission to skip approvals: Row-Bot drafts again once without them, then stops. A draft you leave waits in **Settings › Skills** under **Skill proposals**, marked **From** its chat; deleting the chat deletes the draft. Row-Bot's own offers follow the **Learn new skills** switch in Settings › Preferences (**Create skills while chatting** with Learning); **Save as skill** is always there.

## What Skills Change

Skills shape Row-Bot's behavior; they do not automatically grant credentials or bypass approvals. A skill can make Row-Bot more consistent for a task, but tools still need to be enabled and approved where appropriate.

## Automatic Selection

When progressive discovery is available, Row-Bot can search enabled skills and load a relevant one for the current task. A successful automatic load appears once as **Using _skill_** and adds an active skill chip.

- Automatically selected skills are stored per parent task or child Agent, not per shared Agent Profile.
- Reopening a task restores its selected skills.
- Parent tasks and sibling children do not share automatic activation state.
- Up to five automatically selected skills are retained per task; pinned skills remain separate.
- Loading an already active skill does not show a second **Using _skill_** notice.

Automatic selection changes instructions only. It cannot add a denied tool, alter credentials, bypass approvals, expand a workspace, or change an Agent Profile. Read [Progressive Tools And Skills](/docs/guides/progressive-tools-and-skills) for the complete tool and skill flow.

## Check-ins

**Check-ins** is a built-in skill for people who want Row-Bot to consult them along the way instead of handing back finished work. With it on, Row-Bot asks two or three scoping questions before open-ended work, checks in at milestones ("Here's what I found so far. Does this cover it?"), and confirms before anything high-stakes.

- It used to be called **Proactive Agent** and was pinned in every new chat. It is no longer pinned anywhere: updating Row-Bot unpinned it once, everywhere. A chat where you turned it on yourself keeps it, and you can pin it again.
- Its two most useful habits are now part of every chat: Row-Bot mentions a memory that bears on what you're doing, in one line, and offers at most one obvious next step.
- To use it, type `/check-ins` in a chat, or pin it in **Settings › Skills** (**⋯ › Advanced settings**) to have it in every new chat.
- Check-ins asks questions and pauses for your answers, so long work stops more often. Leave it off if you'd rather Row-Bot carry on until the work is done.

Check-ins changes how Row-Bot behaves inside a chat. Row-Bot speaking first, outside a chat, is [Proactive Row-Bot](/docs/guides/proactive).

## Troubleshooting

- If a skill is not used, make your prompt match its purpose, confirm it is in **Your skills**, or call it with its slash command. The command on its own turns the skill on for the chat; inside a longer message it focuses just that turn on the skill. See [Mention an app or a skill](/docs/chat/#mention-an-app-or-a-skill).
- If a skill is too aggressive, rewrite it with clearer boundaries or remove it.
- If a skill from a catalog is unfamiliar, open **What's inside** before adding it.
