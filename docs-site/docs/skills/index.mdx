# Skills Hub

Skills are instruction packs that teach Row-Bot how to approach a category of work. **Settings › Skills** is where you find skills, add them, try them, and create or edit your own (the command palette's **Add a skill** goes there). Skills you have added can also be discovered and loaded progressively when a task clearly matches their purpose.

See [Settings: Skills](/docs/settings/skills) for the page itself.

## UI Walkthrough

- **Search** finds skills in the library on this computer; **Search online catalogs** asks catalogs such as ClawHub.
- **Your skills** lists the skills you have added, built-in and your own.
- **A skill's page** shows its slash command (**Use it in chat with /_name_**), which agent profiles include it, and **What's inside**: its files and scripts.
- **Add** adds the skill and turns it on. Scripts inside it never run when it is added.
- **Try it** opens a new chat with a draft that uses the skill; nothing is sent until you send it.
- **⋯ › Advanced settings** opens the skill editor, where you edit and pin the skill and review proposed changes.

## Creating A Skill

1. Choose **Create a skill** in Settings › Skills.
2. Decide what task the skill should help with.
3. Write concise instructions, examples, and boundaries, including when the skill should and should not be used.
4. Save it.
5. Test it with **Try it** or a small prompt.
6. Revise if Row-Bot overuses or misunderstands it.

## What Skills Change

Skills shape Row-Bot's behavior; they do not automatically grant credentials or bypass approvals. A skill can make Row-Bot more consistent for a task, but tools still need to be enabled and approved where appropriate.

## Automatic Selection

When progressive discovery is available, Row-Bot can search enabled skills and load a relevant one for the current task. A successful automatic load appears once as **Using _skill_** and adds an active skill chip.

- Automatically selected skills are stored per parent task or child Agent, not per shared Agent Profile.
- Reopening a task restores its selected skills.
- Parent tasks and sibling children do not share automatic activation state.
- Up to five automatically selected skills are retained per task; pinned skills remain separate.
- Loading an already active skill does not add a duplicate receipt.

Automatic selection changes instructions only. It cannot add a denied tool, alter credentials, bypass approvals, expand a workspace, or change an Agent Profile. Read [Progressive Tools And Skills](/docs/guides/progressive-tools-and-skills) for the complete tool and skill flow.

## Troubleshooting

- If a skill is not used, make your prompt match its purpose, confirm it is in **Your skills**, or call it with its slash command. The command on its own turns the skill on for the chat; inside a longer message it focuses just that turn on the skill. See [Mention an app or a skill](/docs/chat/#mention-an-app-or-a-skill).
- If a skill is too aggressive, rewrite it with clearer boundaries or remove it.
- If a skill from a catalog is unfamiliar, open **What's inside** before adding it.
