Feature inventory

The complete workbench

One system.
Every surface.

Row-Bot combines provider-aware reasoning with parent-led agents, durable document processing, goals that keep working, local memory, real tools, authenticated access from your other devices, background workflows, messaging, and reviewable extensions in one conversation-first app. Ask for a deck or a code change and the design or code folder opens beside the chat; approvals, goals, and agents stay with the conversation that owns them. This page documents what ships and where each capability fits.

01 / WORKSPACE

One conversation-first workspace.

The same app runs in the desktop window, in a browser on another computer, and on a phone. Conversations are where work happens: ask, and Row-Bot creates what the task needs and shows it beside the chat. Home gathers everything that is not one conversation, and nothing urgent is hidden.

App tour documentation →Home documentation →

Conversation-first creation

Ask for a deck, a landing page, or a code change and Row-Bot creates the design or code folder the work needs, shown as an inline card with Open, Rename, and Undo. When a request needs a tool or account that is off, the conversation offers Turn on or Connect in place instead of sending you to Settings.

Built inUndoable

Home

Overview opens with an Ask box, then shows what needs you with each fix in place, where you left off, today’s agents and workflow runs, and what happened since yesterday evening; approvals are answered right there. Workflows, Knowledge, Monitor, and Insights sit beside it as tabs, so background work, memory, and health are one click from any conversation.

Built inDesktop + phone

Conversation details

A small card beside each conversation shows what it is working on — designs, code folders, the browser — along with its goal, its outputs, and its agents with Stop and Message. It floats beside a wide chat and opens as a sheet on smaller screens.

Per conversation

Command palette

Press ⌘K or Ctrl+K to search conversations and their messages, commands, settings, and saved workflows at once. Plain intents in any word order, such as “connect telegram”, “turn on developer tools”, or “dark mode”, find the right action, settings switches show their state and change with Undo, and Enter runs only a result that matches what you typed.

Keyboard first

Terminal dock

Open a real terminal on your own shell, docked under the conversation in the desktop app, with colours, history, Tab completion, Stop with Ctrl+C, a height remembered per device, and scrollback that survives closing the dock. Open in your terminal starts your own terminal app at the code folder, and commands the assistant runs still use their approval cards.

DesktopYour shell

Sidebar and settings

The sidebar groups conversations by time and filters them as All, Chats, Designs, Code, or Workflows. Settings sit in six groups with search over pages and single rows, and save as you change them with Undo; appearance follows the operating system in light or dark, and any conversation exports as Markdown or PDF.

Built inLocal
02 / AGENTS

Durable roles, visible goals, coordinated work.

Row-Bot turns a conversation into a controlled working environment. Profiles define how an agent should operate, goals keep long-running intent visible and moving, and one authoritative parent can plan, delegate, join required results, continue through several work waves, and produce the final answer.

Profiles, goals, and agents documentation →

Agent Profiles

Give a conversation a reusable role with instructions, usage guidance, handoff contracts, workspace policy, enabled tools and skills, approval policy, and model preferences. The sidebar’s Agents dialog holds the profile library and your favourites, and profile snapshots travel with delegated work so the operating contract remains explicit.

Built inDesktop + phone

Goals that keep working

Set a goal from the conversation details card or with /goal and Row-Bot starts at once, continuing after each turn until the work is done, with optional turn and time limits. The goal card shows the turn, time running, tokens, the latest progress reason, Pause or Resume, and Stop; a goal pauses with its reason when progress stalls, waits out provider rate limits, stops for approvals, and delivers terminal notices through configured channels.

Built inDesktop + phone

Automatic parent-led orchestration

Delegate required or background work with dependencies, duplicate-objective checks, multiple work waves, live joins, and visible capacity limits. Stop or message a delegated agent from the conversation details card or its own conversation, and answer its approvals in either place. The parent remains responsible for follow-up and the final response.

Built inApproval aware

Checkpointed execution budgets

Bound long-running Agent work with durable model-and-tool round counters, repeat-stall protection, exactly-once finalization, and configurable nesting, concurrency, and active-time limits. Extra child runs wait in a fair queue instead of bypassing capacity.

Bounded executionDurable

Durable joins and recovery

An ordered inbox returns approvals, completions, retries, steering, and stop events to the parent. Checkpoints, leases, and finalization claims recover interrupted work without duplicate synthesis, delivery, or final answers.

Parent linkedExactly once

Buddy desktop overlay

Keep the selected conversation, including one with a design or code folder, in a compact always-available overlay on Windows and macOS. Buddy shares the conversation’s draft, model, tools, approvals, and run state instead of creating a second conversation.

DesktopShared context
03 / MODELS

Local, self-hosted, hosted, or subscription-backed.

Every selection stays provider-qualified from setup through runtime. Row-Bot separates model discovery, credentials, capabilities, readiness, context policy, and transport behavior so similarly named models do not become interchangeable by accident.

Models and providers documentation →

Your model, your choice

A fresh install has no preset chat, vision, image, or video model. The first run asks one question, how Row-Bot should think: on this computer, with your subscription, with an API key, or through a custom endpoint. Your pick becomes the default, and if it later becomes unavailable Row-Bot offers Reconnect or Choose another model instead of silently switching.

No presetsExplicit

One model list

The composer and the Brain, Vision, Image, and Video pickers share one grouped, searchable list with billing tags, and the model pill says Unavailable with the reason when a model cannot run. Vision follows the chat model unless you choose another, and attaching an image to a model that cannot see it offers a vision model.

Built in

Local and self-hosted models

Discover and use Ollama plus OpenAI-compatible runtimes such as LM Studio, vLLM, llama.cpp, LocalAI, LiteLLM, SGLang, and oMLX. Local endpoints remain distinct from hosted services and can work offline when their runtime and model are local.

LocalOffline capable

Hosted API providers

Connect OpenAI, Anthropic, Google AI, xAI, OpenRouter, Requesty, Atlas Cloud, MiniMax, OpenCode providers, Ollama Cloud, and custom endpoints. Capability mapping routes chat, tools, reasoning, vision, image, and video models to compatible surfaces.

OptionalHosted

Subscription sign-in

Keep xAI Grok OAuth, ChatGPT/Codex, and Claude Subscription authentication separate from API-key providers. OAuth health, credential source, model visibility, and runtime readiness appear in provider settings.

OAuthOptional

Automatic catalog discovery

Targeted, startup, and scheduled refreshes discover newly available models through provider-scoped saved credentials. Last-known-good provider rows survive failed or incomplete refreshes, while live, cached, fallback, and empty outcomes remain visible.

Resilient discovery

Context and prompt cache

The composer’s context meter estimates the complete next model input, including system prompts, images, and bound tool schemas. Model-aware rolling compaction starts with safe headroom, preserves recent complete turns, and records durable status, while prompt-cache diagnostics and provider-specific reporting keep long conversations predictable.

Built in

Provider-safe tool schemas

Inspect the effective schema sent through each adapter. Gemini-compatible filtering catches untyped arrays before a request is made, while unaffected providers keep the original tool contract and explicitly requested incompatible tools fail clearly.

Provider aware

05 / KNOWLEDGE

Memory that remains inspectable.

Useful recall needs more than an opaque summary. Row-Bot stores structured local records, combines semantic, lexical, and graph signals, and keeps review state and trace information available when you need to understand why something returned.

Knowledge and memory documentation →

Personal knowledge graph

Represent people, projects, preferences, facts, events, documents, and other entities as typed nodes and relationships. Explore them on Home’s Knowledge tab, where a WebGL graph shows up to 2,000 memories (5,000 with Show all), focuses a memory’s neighbourhood, and filters by type, beside the review queue, bulk actions, Add memory, and activity logs. Vague relation types are refused before saving, and inconsistent records can be repaired.

LocalAuditable

Bounded hybrid recall

Combine configurable embeddings, FAISS semantic search, FTS5 lexical matching, and bounded graph expansion. Local embedding startup is cache-only, downloads and repair are explicit, and missing models fall back quickly to lexical and graph retrieval instead of stalling the request.

Bounded recallLocal by default

Durable document ingestion

Stream bounded uploads into a persistent SQLite queue, deduplicate content, make the complete batch searchable before extraction, and publish sharded vector manifests atomically. Pause, resume, cancel, retry, repair, and restart without losing safe progress.

Built inResumable

Resumable extraction

Extract knowledge from PDFs, spreadsheets, JSON, TSV, images, and common text formats through bounded map-and-reduce checkpoints. Source metadata stays attached and final document, graph, and Wiki Vault updates commit idempotently.

TraceableIdempotent

Wiki Vault and Dream Cycle

Export an Obsidian-compatible local wiki with readable article names, synchronise selected knowledge, and let the idle-aware Dream Cycle consolidate memory or prepare bounded improvement proposals while preserving busy-state and review controls.

The builder keeps steps in an ordered list with the schedule written in words, suggests variables and step outputs as you type {{, and keeps the graph editor one toggle away; webhook triggers show their address with Copy and accept their secret as a header.

Approvals and delivery

Pause consequential actions for approval in the app or supported channels. Results always arrive in the app, plus any configured channels you tick; workflow-level delivery defaults distinguish no destinations from inherited destinations, and channel retries retain terminal notices until they can be reconciled.

Approval aware

Run history and diagnostics

07 / ACCESS

One owner. Every device.

The desktop app, a browser on another computer, and a phone open the same app against the same Row-Bot host. The host remains the system of record, a small screen changes layout rather than authority, and every signed-in device can be reviewed and signed out.

Remote access documentation →Phone layout documentation →

Guided connection

Connect a phone or computer from Settings › Devices & remote access. Row-Bot detects the ways in — Tailscale for private HTTPS, the same Wi-Fi, or the internet through your public link — then shows one QR code backed by a one-time invitation that renews itself, waits for the device, and shows how to install Row-Bot on that phone.

Optional remote accessGuided

Phone and tablet layout

Small screens get one header, the sidebar as a drawer with the same filters, panels as full-height sheets, and every Settings page. Create conversations, attach files, choose profiles and models, approve work, and stop active runs away from the desk.

Desktop + phone

Your devices

See each signed-in device by name, which one you are using, and where and when it was last seen in plain words. Rename a device or sign it out, which ends every session of that device; invited devices renew their session in the app and never revive a revoked one.

Revocable

Invitations and sessions

Create origin-bound, expiring, one-time invitations from the app or CLI. Instance-isolated HttpOnly sessions renew authoritatively, record secret-free audit events, and support logout plus immediate session or device revocation.

AuthenticatedRevocable

Authenticated server mode

Run row-bot serve for a long-lived headless host. HTTP requests and the live event stream share exact-origin, allowed-host, trusted-proxy, and authenticated-owner gates; server loopback does not bypass authentication.

Designs and code folders, beside the conversation.

Design and code work happens in the conversation that asks for it. A design or code folder belongs to that conversation and opens in its Design or Developer panel beside the chat, so you can ask for a change, watch it land, review it, and keep going. Generated designs stay editable; repository changes stay reviewable.

Make decks, documents, landing pages, app mockups, and storyboards from a request, Add resource, or Home’s New design. The Size menu offers 16:9, 4:3, square, A4, and phone and re-fits every page, anything unusual is one request away, and brand colours and fonts can come from a website.

DesktopFive kinds

The Design panel

Switch between Preview and Edit, select any element to ask Row-Bot for a bounded change, or double-click text to edit it in place. Pages, undo and redo, saved versions, and a review that fixes issues one by one or every safe one at once keep iteration reviewable.

11 / PRIVACY

Control is a system property.

Local-first means durable application state belongs to the user, external routes are explicit, and consequential actions remain reviewable. It does not pretend that a hosted model or online tool can be used without sending that service the data required for the request.

Privacy and safety documentation →

Local durable data

Store conversations, profiles, goals, orchestration records, workflows, document queues and indexes, memory, designs, plugin state, code context, and owner access records under the Row-Bot data directory.

Local

Credential protection

Use the operating-system credential store on desktop or an isolated encryption key with encrypted provider and channel records in server deployments. Read-only secret directories, safe fingerprints, and redacted status keep plaintext credentials out of application metadata and diagnostics.

Encrypted at rest

Approval and risk policy

Classify destructive, networked, private-data, metered, installation, Git, shell, browser, channel, and MCP actions conservatively. Approve or Deny in place — in the conversation, the attention indicator’s list, Home’s Overview, a floating notice, Buddy, or a supported channel — with bounded reasons. Approvals wait until answered and survive restarts, while the original action payload is retained for the decision.

Reviewable

No hidden Row-Bot cloud

Row-Bot has no required account, hosted sync service, or first-party telemetry pipeline. Optional providers, channels, tunnels, updates, search, and external tools remain individually visible choices. The opt-in Cua Driver has separately disclosed, consent-gated third-party telemetry; it is the reviewed exception, not Row-Bot telemetry.

No first-party telemetryExplicit services

Backup and restore

Back up now writes one zip to the workspace’s Backups folder without keys, sign-ins, sessions, caches, logs, or runtimes, and lists what to set up again. Restore from backup checks the archive, applies it at the next start, keeps the current profile aside, and rolls back if anything fails.

LocalNo secrets

Conversation cleanup

Select conversations in the library with filter-aware bulk controls and remove them through one cleanup path. Active work is cancelled before deletion, while dirty Developer recovery state, code folders, and design ownership are preserved.

Explicit actionRecovery aware
