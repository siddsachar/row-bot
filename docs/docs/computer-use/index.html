Computer Use

With computer use, Row-Bot works in an app on this computer the way you would: it looks at the app's window, then clicks, types, scrolls and presses keys with your real mouse and keyboard while you watch. Use it for desktop apps, or for your own browser when you ask for it. For websites, Row-Bot's own browser is usually better (see Tools, Approvals And Background Work).

Computer use is off by default. It works in Row-Bot on this computer: in a chat, a workflow, a goal or a helper agent, one conversation at a time, each app asking first by the approval level. It never runs from a channel chat (Telegram, Slack and the like), since you're usually away from the screen.

Set It Up​

  1. Open Settings › System and choose Browser and computer use › Set up….
  2. Under Desktop apps, read the notice about Cua Driver (the open-source program Row-Bot uses for the mouse, keyboard and window pictures) and accept it if you agree.
  3. Choose Install Cua Driver. Row-Bot downloads the reviewed Cua Driver 0.20.0 for your computer, checks its SHA-256 and keeps it in Row-Bot's data folder.
  4. On a Mac, allow Row-Bot in Accessibility and Screen Recording (the buttons open them), then choose Check setup.
  5. Turn on Computer use. Test with Calculator opens Calculator and takes a picture of it to show it works.

Use your own Cua Driver accepts a separately reviewed copy after a version check; Remove Cua Driver deletes Row-Bot's copy and turns computer use off.

What You See​

  • The Stop bar. While Row-Bot uses an app, a slim bar stays on top of your screen: "Row-Bot is using Microsoft Edge · Esc to stop · Stop". Press Esc or Stop to end the reply at once; the chat's own Stop does the same from any device.
  • In the chat. A step shows Using Microsoft Edge, the window, what Row-Bot just did ("Clicked "Leak"") and a live picture of the window, with Stop. The picture is only on this computer's Row-Bot app and is never saved.
  • Your hand on the mouse. If you move the mouse, click or type while Row-Bot works, it pauses before its next step and asks "Carry on?" in the chat. Choose Carry on and it looks at the screen again; Stop ends it. Nothing it was about to do happens without a fresh look.

What Asks First​

  • The first use of each app in a chat: "Let Row-Bot use Microsoft Edge in this chat?". After you allow it, that app doesn't ask again in that chat.
  • Paying, buying, booking with a charge, sending, posting, deleting files and changing system settings. The card says what will happen ("Row-Bot will click "Confirm and pay £60" in Microsoft Edge. This can charge you.") and shows the window with a ring where Row-Bot will click.

How each is decided follows the chat's approval level: Ask asks you, Auto's reviewer approves what clearly matches your request (otherwise it asks you), Hands-off goes ahead, and Block refuses.

Row-Bot never types a password, one-time code or card number: it asks you to type it, then carries on. It doesn't control password managers, Row-Bot itself or protected system screens, and it doesn't press the keys that open other apps (the Windows key, Spotlight, Ctrl+Alt+Delete). In a terminal it types each command and never pastes, and every command is checked as its shell tool checks one: a read-only command such as git status just runs, anything else asks by the approval level on the same Run shell command card, and blocked commands and Row-Bot's private data never run. That lets it use a REPL or an interactive command-line tool.

How It Works​

  • Each step works on one window: Row-Bot brings it to the front, acts, then takes a new picture. A model that sees images gets that picture with each step and checks it itself; a model without vision gets a list of the window's controls and where they are.
  • Pictures stay in memory. They are never written to the chat, memory, logs or files, and password, code and card fields are covered in the model's picture.
  • If Windows keeps another window in front (for example, the screen is locked), Row-Bot clicks and types nothing and says so.

Record The Screen​

With computer use set up, Row-Bot can record your main screen to a video when you ask. It asks first ("Record your screen?"): the recording shows everything on the screen, including other apps and notifications. The conversation shows Recording · 0:42 with Stop; the video (MP4) is saved to the conversation's files and shows there with a player. It stops when you or Row-Bot stop it, at its time limit (5 minutes unless asked otherwise, at most 10), before it gets too large for the chat, when the conversation is deleted, and when Row-Bot quits.

  • On Windows, Cua Driver records video with ffmpeg. Row-Bot uses the one on this computer, or asks on the same card to download it first (about 30 MB, from PyPI; see ffmpeg). On macOS it needs macOS 15 or later and Screen Recording permission.
  • The recording runs in a Cua session of its own, into a private folder in Row-Bot's data; the folder (including Cua's per-step pictures) is removed once the video is saved.
  • Without computer use set up, Row-Bot says that recording the screen needs it and how to set it up. Its own browser can be recorded without it (see Tools, Approvals And Background Work).

Privacy And Cua Telemetry​

The reviewed Cua 0.20.0 telemetry sends pseudonymous installation/process-session identifiers and bounded product, platform, client, tool/outcome, duration/output, aggregate session/config/cursor/recording, permission, and lifecycle categories to Cua's EU PostHog endpoint. Its tagged event builders do not receive prompts, tool arguments/results, typed text, screenshots, accessibility trees, app/window names, URLs, paths, raw config/cursor values, or raw errors. Row-Bot's own telemetry is only install stats (see Install Stats), and Row-Bot keeps its prompts, files, memories, secrets, screenshots, tool arguments, and channel content outside Cua telemetry.

For the exact allowlist and reviewed dependency record, see Computer Use: architecture and security decision.

Troubleshooting​

  • "Computer use isn't set up yet": the chat's step links to Settings › System › Browser and computer use; finish the setup there.
  • "Windows didn't let Row-Bot bring … to the front": unlock the screen, or click the app's window once, then ask again.
  • "Row-Bot is using the computer in another chat": wait for that reply to finish, or stop it there (or press Esc).
  • No window found: Row-Bot lists open windows with their titles; name the app, or words from its window's title. It can open an app by its name after asking.
  • On a Mac, if Row-Bot reports missing permission, allow it in Accessibility and Screen Recording, then Check setup.
