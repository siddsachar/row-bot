Apps Controls​

Group: Connections. Open in Row-Bot: /app-v2/settings/apps. Guide: /docs/settings/apps.

Dependencies: Apps that run on this computer may need Node.js or uv, which Row-Bot prepares after you agree. Channels need the matching channel extra and third-party account configuration.

Security: Nothing is fetched or run until you agree; deleting, sending, paying, publishing, running code and unknown actions always ask first. Signing in to an account opens an external authorisation flow, and a running channel can receive or deliver real messages.
